# PFE-ECOSURF

## Quick start (Windows)
1) Copy `credentials.json` into the same folder as `main.py` (project root).
2) Run:
   ```bash
   pip install -r requirements.txt
   python scripts/setup_perch.py --install --run
   ```

This downloads embeddings/clusters into `perch2/`, installs dependencies, and launches the app.
